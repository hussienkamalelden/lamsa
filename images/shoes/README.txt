# صور قسم: كوتشيهات وأحذية  (images/shoes/)

كل صورة مربوطة بمنتج في js/data.js:

1.jpg    ← حذاء كاجوال جلد عسلي  (s1)
2.jpg    ← حذاء جلد طبي بني  (s2)
3.jpg    ← حذاء جلد طبيعي - أسود وبني  (s3)
4.jpg    ← حذاء ديربي جلد محبب  (s4)
5.jpg    ← حذاء أكسفورد بروج كلاسيك  (s5)
6.jpg    ← حذاء موكاسين جلد بني  (s6)

عشان تغيّر صورة: حط الصورة الجديدة بنفس الاسم (مثلاً 3.jpg).
عشان تزود صور للمعرض: حطها هنا (مثلاً 3-2.jpg) وضيف اسمها في imgs بتاعة المنتج في js/data.js.
المقاس الأفضل: 1200×1500 (نسبة 4:5).
