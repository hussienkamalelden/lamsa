# لمسة — Lamsa Store (Template)

تمبلت HTML/CSS/JS لمتجر إلكتروني متعدد الأقسام، كل قسم ليه ألوانه. الاسم مؤقت.

## التشغيل
- افتح `index.html` في المتصفح مباشرة، أو
- `python -m http.server 5510` جوه الفولدر وافتح http://localhost:5510

## الصور
كل قسم ليه فولدر جوه `images/` فيه صور متسمية `1` لـ `6`، وجواه `README.txt` بيقول كل صورة لأنهي منتج:

```
images/women  images/men  images/kids  images/shoes  images/home  images/acc
```

- كل منتج في `js/data.js` ليه `imgs` بأسماء صوره بالظبط، مثلاً `['3.jpg']`.
- لتغيير صورة: حط الجديدة بنفس الاسم.
- لصور زيادة في معرض صفحة المنتج: حطها في الفولدر (مثلاً `3-2.jpg`) وضيفها في `imgs` → `['3.jpg', '3-2.jpg']`.
- المقاس المفضل: 1200×1500 (نسبة 4:5).
- لو صورة ناقصة بيظهر placeholder بلون القسم.

## الصفحات
| الصفحة | الملف |
|---|---|
| الرئيسية: Hero slider بالأقسام، الأقسام، الأكثر مشاهدة (slider)، كل المنتجات بفلتر وترتيب | `index.html` |
| القسم بألوانه: `category.html?c=women` | `category.html` |
| المنتج: معرض صور (slider)، لون، مقاس، كمية، أضف للسلة / اشتري الآن، منتجات مشابهة، الأكثر مشاهدة | `product.html?id=w1` |
| السلة | `cart.html` |
| إتمام الشراء + تأكيد الطلب | `checkout.html` |

## ألوان الأقسام (`css/style.css` ← `[data-cat=...]`)
| القسم | id | اللون |
|---|---|---|
| ملابس حريمي | women | وردي |
| ملابس رجالي | men | أزرق غامق |
| ملابس أطفال | kids | أزرق فاتح |
| كوتشيهات وأحذية | shoes | بنفسجي |
| أدوات منزلية | home | أخضر |
| إكسسوارات | acc | عسلي |

لإضافة قسم: ضيفه في `CATEGORIES` في `js/data.js` + بلوك ألوان `[data-cat="..."]` في الـ CSS + أيقونة في `CAT_ICON_PATHS` في `js/app.js` + فولدر صور.

## الهيكل
```
css/style.css        نظام التصميم + ألوان الأقسام + الـ responsive
js/data.js           الأقسام والمنتجات (بيانات تجريبية ← هتتبدل بـ API)
js/app.js            الهيدر/الفوتر/منيو الموبايل، السلة، كارت المنتج، الصور، Slider
js/pages/*.js        سكريبت كل صفحة
images/<category>/   صور المنتجات
```

## ملاحظات للمرحلة الجاية (الباك إند)
- السلة في localStorage — هتتنقل للسيرفر.
- الدفع بالكارت/المحفظة واجهة بس.
- مفيش تسجيل دخول (Guest checkout).
- بعد أي تعديل في CSS/JS غيّر رقم `?v=9` في لينكات الصفحات عشان المتصفح ما يعرضش النسخة القديمة.
